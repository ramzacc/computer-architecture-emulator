Grid Canvas

Components

Pick a known component, then click the grid to place it. Only its type + position are saved.

Wire mode (top bar): start from a component pin, then extend orthogonally. Click a wire to select its net, Delete to remove it, right-click to remove one segment.

Pan mode (top bar, the default): drag empty canvas to move around; click to select, drag a component to move it, or click the grid to place the component picked above. Exactly one mode is always active, so switching between Wire and Pan never leaves you modeless.

A net is ON (lighter) when it reaches a source component's pin (CPU, GPU, Clock, Control). That energization is derived live and never saved.
